# 数字系统设计
## 分数构成
40%平时+60%期末。共4次小测（赋分制）

这门课知识点不多，但是考试、小测比较灵活
## 学习路径
不听课，直接学[ximo的视频](https://www.bilibili.com/video/BV1kZ4y1w7dy/?share_source=copy_web&vd_source=175c3506a13fcf2ad63dc8048788a09e)，其中AD/DA部分不用学，ROM/RAM部分要另外看[清华王红老师的视频](https://www.bilibili.com/video/BV18p411Z7ce/?p=39&share_source=copy_web&vd_source=175c3506a13fcf2ad63dc8048788a09e)，微控制器部分主要听习题课助教讲解和前辈笔记，小测、作业、历年卷的题目多加练习，题型比较固定，熟练掌握后基本没问题

???+ warning
    今年期末和往年不太一样，脉冲电路只考了一个基本的单稳态电路，微控制器比较常规，但是门电路部分考的比较细比较难，设计模拟电路的计算，但是门电路平时上课基本不讲。门电路部分可以看[ximo的门电路讲解视频](https://www.bilibili.com/video/BV1kZ4y1w7dy/?p=12&share_source=copy_web&vd_source=175c3506a13fcf2ad63dc8048788a09e)，着重理解输入高电平、低电平状态下各个三极管的工作状态
