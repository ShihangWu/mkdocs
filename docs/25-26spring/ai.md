# 人工智能
50%平时+50%期末 

平时成绩：5次作业 + 1次小组展示

期末：中文，半开卷，可携带1张A4纸。8道大题，搜索、对抗搜素（$\alpha-\beta$剪枝）、CSP问题、命题逻辑、贝叶斯网络、决策树、神经网络、马尔可夫决策过程（MDP） 各一道，难度不大，最好熟练掌握贝叶斯网络的计算

???+ warning

    这门课从24级开始从大三下移到了大二下，如果之前没有接触过算法等课程，则需要多加练习
